# 2026-10-30: Profiles

Status: **implemented; API verified with tests; live browser check pending** (the running dev API kept its old process again and needs a restart of `pnpm dev`).
Gate: G4 (Faroz)   Decision: D-25 (owner-approved in the chat, 2026-10-30)   Design: no handoff screen; built in the Faroz style (covers and accents from the brand tokens)

## Context

The owner asked for a profile page: set up your own profile, add a photo and style it, and let others open its public part and see only what is allowed. The quality bar was high.

## Changes

**Shared:** `packages/shared/src/profile-api.ts`.
- Settings, my profile and public profile schemas.
- The handle rule, the cover and accent presets, the default visibility.
- `canSeeBlock`: the one visibility rule used by both the API and the editor preview.

**Database:** migration `20261030140000_profiles` (additive): `profiles` and `profile_avatars`. Applied and SHA-256 pinned.

**API:** `apps/api/src/profiles/`.
- **Who is asking:** any signed-in person. Guests cannot own a profile.
- **My profile:** read, save, handle check. The handle is suggested from the name, with Russian and Tajik transliteration.
- **Photo:** upload with magic-byte check and a 1 MB limit; removal; served at a versioned URL.
- **Public view per viewer:**
  - `relation` comes from shared class groups.
  - Each block is hidden by its visibility.
  - Learning results are never shown to center staff.
  - The learning block uses the same `ProgressService.stats` as the learner's sidebar.
  - `canMessage` follows the chat contacts.
- **Chats:** contacts, peers and group members now carry `avatarUrl`.

**Web:** `apps/web/src/features/profile/`.
- **Editor**, "My profile" at `/app/profile`, `/teach/profile` and `/center/profile`, opened from the sidebar person card:
  - **Photo and style:** crop dialog (drag, wheel, slider, arrow keys; round mask; 512 px WebP), remove photo, five cover gradients, five accent colours.
  - **About:** handle with a live check and the `faroz/u/` prefix, headline and bio with counters, city, languages, interest tags (Enter to add, Backspace to remove).
  - **Links:** up to four, https only.
  - **Teaching:** teachers only.
  - **Privacy:** Everyone / My groups / Only me per block, plus "show when I am online".
  - **Live preview:** "as my groups see it" or "as everyone else sees it".
  - **Saving:** a sticky save bar while there are changes; copy link; open the public page.
- **Public page** `/u/<handle or key>` (not indexed):
  - Cover, photo ring in the accent colour, role, @handle, online state and headline.
  - Blocks: about, learning (level ring, XP, streak, badges), teaching, interests, links (`noopener noreferrer nofollow`), groups.
  - "Message" opens the chat; "Edit" for the owner; copy link.
  - States: sign-in prompt, not found, loading skeleton.
- **Photos everywhere:** the sidebar card, chat lists and headers, members panel, people picker and the incoming call. Names in chats open the profile.
- **Messages:** `Profile.*` in tg/ru/en. The ru and tg texts are AI drafts and **need review**.
