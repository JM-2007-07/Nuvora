## 1. What the project is

**Faroz** (formerly Nuvora; "Nuvora" must never appear in the UI) is a multilingual (ru default, tg, en) EdTech platform. Learners take a diagnostic, see gaps per topic, get quests (lesson → retest) and see before/after. Teachers see their groups answer by answer. Centers see group totals and participation only (never individual scores/answers, never who got practice). **Defense: Mon 2 Nov 2026; implementation deadline Sun 1 Nov.** The owner wants an honest, working full-stack MVP: every button works through the real backend, beautiful animated site.

## 3. Run and verify

- Dev servers via `.claude/launch.json`: `api` (:4000, `nest start --watch`), `web` (:3000, often taken by another chat's `next dev`), `web-prod` (`next start`, :3001 or the next free port). Prefer verifying on a production build: `pnpm --filter @nuvora/web build`, then `web-prod`.
- Checks: `pnpm lint`, `pnpm typecheck`, `pnpm test` (api 146 unit + 75 e2e, web i18n parity), `pnpm build`, `pnpm seed:check`.
- Playwright (installed Edge): `apps/web/e2e/*.spec.ts`, 10 tests. To run against a prod build, create a temporary `apps/web/playwright.tmp-prod.config.ts` that spreads `playwright.config.ts` with `use.baseURL: 'http://localhost:3001'` and `webServer: undefined`, run `npx playwright test -c playwright.tmp-prod.config.ts`, then **delete it**.
- **Gotchas:**
  - `pnpm build`, `pnpm test`/`seed:check` rebuild `apps/api/dist` and can kill the running API watcher → check `http://localhost:4000/api/v1/plans`; restart the `api` preview if needed.
  - On Windows, renaming folders under `apps/web/src/app` fails while a `next dev` runs: move files one by one.
  - Bash heredocs containing `'` sometimes fail to parse: write files with the Write tool instead.
  - `pnpm format:check` fails on ~200 files from before this work (line endings); not a regression.
